# 🦆 Jo Ken Duck

**Pedra, papel e tesoura. Só que seu adversário é um pato.**

Jo Ken Duck é uma versão divertida do clássico jogo Pedra, Papel e Tesoura, em que você enfrenta uma inteligência artificial controlada por um pato. Escolha sua jogada, desafie seu adversário emplumado e descubra quem leva a melhor nessa disputa!

## 🎮 Sobre o projeto

O objetivo do Jo Ken Duck é transformar um jogo clássico em uma experiência interativa e descontraída, colocando o jogador frente a frente com um oponente inusitado: um pato!

Este projeto foi desenvolvido como parte do meu portfólio de programação, com foco na prática de desenvolvimento web, lógica de programação e criação de interfaces interativas.

## ✨ Funcionalidades

- 🪨 Escolher entre pedra, papel e tesoura.
- 🦆 Jogar contra um pato que faz escolhas aleatórias.
- ⚔️ Comparar as jogadas para determinar o vencedor de cada rodada.
- 🏆 Acompanhar o resultado das partidas.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
